## Resume work without rebuilding the conversation

1. Open the canonical brief and take its **Next step**.
2. Update that file with the decision, source or asset link; keep rejected alternatives in its decision notes.
3. Update the index only if status or focus changes. Link to the brief from scripts and prompts rather than copying its specifications.
4. Before release, check historical claims, image consistency, branding and asset permissions; add the actual published URL to the editorial entry.

Work one concept forward at a time. “Active” preserves an accepted direction; it is not a commitment to produce everything simultaneously. Keep Australian English, metric units, single-view images unless a collage is explicitly requested, and natural photographic lighting.
